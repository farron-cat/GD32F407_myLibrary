# 三、🔴 发现的问题（按严重程度）

## P1. `PB10` 被代码当 USART2_TX，硬件上是 **LCD 背光**

```c
// Hardware/msp_uart/msp_uart.c:27-48
USART_HandleTypeDef husart2 = {
    .usartx_tx_port = GPIOB, .usartx_tx_pin = GPIO_PIN_10, .usartx_tx_af = GPIO_AF_7,
```
而 PCB：`U9.23 (=PB10) → net LCD_BLK → CN20.7 + U10.7`（LCD 排线的背光脚）。

**后果**：`msp_uart_init()` 一执行，PB10 就被配成 AF7 推挽输出；`printf` 之外的串口空闲电平（高）会**直接持续驱动 LCD 背光网络**，导致背光常亮/常灭或被串口数据"闪灯"。

**建议**：把 USART2 的 TX 换到排针上真正空闲的引脚（如 `PB11` 单独做 TX 也不行，因为它只是排针引出）。板上被引到外部且**空闲**的引脚有：`PD3/PC9/PC8/PC12/PD2/PC11/PC10/PC13/PE6/PE5/PE4/PE3/PE2/PE1/PE0/PE7/PE9/PE11/PE13/PE15/PE12/PE14/PA15/PA8/PC7/PD5/PA0/PA1/PA3/PA4/PA6/PC4/PC5/PD7/PD6/PA2/PC5`（部分已占）。**最干净的选择是 `PD3`/`PC9`（仅接排针）。** 若确实要用 USART2，需要改硬件或改引脚。

## P2. `PC3` 同时是 **KEY4** 和 **EXTI3**

```c
// Hardware/msp_exti/msp_exti.h:9,27-35
#define USE_EXTI3 1
#define EXTI3_PORT GPIOC
#define EXTI3_PIN  GPIO_PIN_3
```
```c
// Driver/bsp_keys/bsp_keys.c:8
{RCU_GPIOC, GPIOC, GPIO_PIN_3}, // KEY4
```
PCB：`U9.57 (=PC3) → KEY4 → SW20 → R14 → GND`。

**后果**：PC3 上只挂了一个物理按键。所以 `msp_exti_init()` 之后 `bsp_keys_config()` 再把它重配为输入（EXTI 线由 SYSCFG 决定，不会被关掉），**按 KEY4 会同时产生 EXTI3 中断和 key 事件**。

**建议**：如果 KEY4 兼任唤醒/中断键，这是**有意设计**，建议补注释；否则把 `USE_EXTI3` 关掉（`#define USE_EXTI3 0`），避免中断与轮询竞争。

## P3. `EXTI0` 用的 `PA0` 在板上**没有任何上下拉**

`EXTI0_PUPD` 是 `GPIO_PUPD_NONE`，触发方式是 `EXTI_TRIG_BOTH`。PA0 只引到 P3.3 排针，悬空时是**浮空输入 + 双边沿** → 极易被干扰、产生大量伪中断。

**建议**：改成 `GPIO_PUPD_PULLUP`（或 PULLDOWN）并视外部信号改为单边沿；或确认 P3.3 一定接了外部信号。

# 四、✅ 确认正确的部分（可放心）

1. **LED 阵列与极性**：拓扑是 `VCC → Q1(PNP) → LED 公共阳极`，`LED 阴极 → R15~R22 → PD8~PD15`。所以 `PC6 低 = 使能`、`PDx 低 = 点亮`——与代码 `bsp_leds_config/open` 的 `gpio_bit_reset` 语义**完全吻合**。
2. **按键**：SW17~SW20 经 R11~R14 到 **GND**，配上拉输入检低 → 代码正确（不需要驱动行/列线）。
3. **I2C 开漏配置**：板上 **R7(→VCC) 接 PB6、R8(→VCC) 接 PB7**，外部上拉已存在，所以 `GPIO_OTYPE_OD + GPIO_PUPD_NONE` 是**正确的**（此前我在只看原理图时标记的疑点已排除）。
4. **蜂鸣器驱动极性**：PB9 高 → Q2(NPN) 导通 → 响。PWM 输出正常。
5. **USART0 用 PA9/PA10 是对的**：模块根本没引出这两个脚，它们就是板载 USB-TTL 的串口 —— `printf` 重定向到这里正是调试口。
6. **RTC 时钟源用 HXTAL 是对的**：板上唯一的 32.768kHz 晶振 `X2` 接在 **PCF8563** 的 OSCO/OSCI 上，MCU 侧没有 32.768k 晶振 → 代码用 `RCU_RTC_HXTAL_DIV25`（8M/25=320kHz，`0x7F/0x9C3` → 1Hz ✅）合法，`RCU_RTCSRC_LXTAL` 分支在这块板上不可用。
7. **PCF8563 寄存器写入正确**：`0x02`起 7 字节 = 秒/分/时/日/周/月/年，BCD 格式无误。

# 六、建议的最小修改清单

```c
// 1) msp_exti.h —— 若不打算让 KEY4 兼做中断，关掉 EXTI3
#define USE_EXTI3 0

// 2) msp_exti.h —— PA0 悬空，改为上拉，避免伪中断
#define EXTI0_PUPD GPIO_PUPD_PULLUP

// 3) msp_uart.c —— husart2 的 TX 改到仅接排针的空闲脚（示例：PD3）
.usartx_tx_rcu  = RCU_GPIOD,
.usartx_tx_port = GPIOD,
.usartx_tx_pin  = GPIO_PIN_3,
.usartx_tx_af   = GPIO_AF_7,   // 需先核实 GD32F407 PD3 的 USART2_TX 复用编号
```
> ⚠️ 第 3 条需要注意：**GD32F407 的 USART2_TX 只能落在 PA2 / PD5 / PB10 / PC10 等固定复用脚上**，不能随便挪。若必须用 USART2 且不能占用 LCD 背光，最现实的做法是**改硬件**（把 LCD_BLK 换到别的脚），或**干脆不用 USART2**（板载 USB-TTL 用的是 USART0/PA9/PA10）。
